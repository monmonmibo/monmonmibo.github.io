- [Home](https://monmonmibo.github.io/)
- [Chiang Mai Trip 2026](https://monmonmibo.github.io/cnx26) 🇹🇭 (Nov-Dec 2026 - Upcoming)
- [Kobe & Awaji Trip](https://monmonmibo.github.io/ukb26) 🇯🇵 (Oct-Nov 2026)
- [Takamatsu Trip](https://monmonmibo.github.io/tak26) 🇯🇵 (Sep 2026 - New!)
- [Nagoya Trip](https://monmonmibo.github.io/ngo26) 🇯🇵
- [Chiang Mai Trip 2025](https://monmonmibo.github.io/cnx25) 🇹🇭
- [Da Nang Trip](https://monmonmibo.github.io/danang26) 🇻🇳 (Apr 2026)

## Local Development

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually:

```bash
http://localhost:5173
```

## Build

```bash
npm run build
```
