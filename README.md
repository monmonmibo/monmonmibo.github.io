# MonMonMibo

Personal travel archive and offline-capable PWA built with Vite and React. The home page lists trips, and each trip shares a timeline, tools, and map layout.

See [DESIGN.md](DESIGN.md) for the copied Airbnb reference, [DESIGN.project.md](DESIGN.project.md) for the local chestnut-and-cream adaptations and [AGENTS.md](AGENTS.md) for code and itinerary conventions.

The UI uses text-first trip cards, small SVG icons, and system fonts. Destination photos and external webfonts are intentionally omitted to keep loading lightweight.

## Local Development

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually:

```bash
http://localhost:5173
```

## Build

```bash
npm run build
```
