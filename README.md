# MonMonMibo

MonMonMibo keeps upcoming and past trips in one place. Open a trip to see its day-by-day itinerary, map, and currency converter. The app can show previously loaded trip details offline. It runs on Vite and React.

See [DESIGN.md](DESIGN.md) for the copied Airbnb reference, [DESIGN.project.md](DESIGN.project.md) for the local chestnut-and-cream adaptations and [AGENTS.md](AGENTS.md) for code and itinerary conventions.

Trip cards use text, small SVG icons, and system fonts to keep pages quick to load.

## Local Development

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually:

```bash
http://localhost:5173
```
