# CNX26 清邁自訂地圖

期間：2026年11月26日至12月1日。初版包含已確認的兩間酒店及清邁機場，共3個地點；尚未加入未確定的餐廳或景點。

## 匯入 Google My Maps

1. 開啟 https://www.google.com/mymaps 並建立新地圖，命名「CNX26 清邁｜2026.11.26–12.01」。
2. 在新圖層點「匯入」，選擇本目錄的 `CNX26-places.csv`。
3. 定位欄位選「地址」，標記標題選「名稱」。
4. 按「分類」設定樣式，將住宿與機場分色。
5. 檢查三個標記是否對應酒店／機場，尤其酒店入口。地址由 Google 匯入時定位，本檔沒有猜測座標。
6. 完成後複製 My Maps 分享或嵌入連結，再加入網站；目前未建立線上 My Maps，亦未修改分享權限。

此檔提供地點標記及行程備註，沒有聲稱提供實際道路導航路線。
